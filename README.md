## 1. Introdução ao Java e ao JDK 25

### 1.1 O que é Java?

Java é uma linguagem de programação **orientada a objetos**, **multiplataforma** e **fortemente tipada**, criada pela Sun Microsystems em 1995. Seu slogan histórico é *"Write Once, Run Anywhere"* — escreva uma vez, execute em qualquer lugar.

### 1.2 Como o Java funciona?

```
Código-fonte (.java)
       ↓  javac (compilador)
   Bytecode (.class)
       ↓  JVM (Java Virtual Machine)
   Resultado na tela
```

A **JVM** traduz o bytecode para o sistema operacional específico. Por isso o mesmo `.class` roda no Windows, Linux ou macOS sem modificação.

### 1.3 Novidades do JDK 25 LTS

| Recurso | O que faz | Exemplo |
|---|---|---|
| **Unnamed Classes** | Dispensa `public class` em arquivos simples | `void main() { }` |
| **`java.lang.IO`** | Substituto mais curto de `System.out` | `IO.println("Olá")` |
| **`var`** | Java infere o tipo automaticamente | `var nome = "Maria"` |
| **Records** | Classes de dados com menos código | `record Aluno(String nome, int idade) {}` |
| **Sealed Classes** | Controla quem pode herdar | `sealed class Forma permits Circulo` |
| **Pattern Matching** | `instanceof` com captura direta | `if (obj instanceof String s)` |

## 2. Conceitos Fundamentais de POO

### 2.1 O que é Programação Orientada a Objetos?

POO é um **paradigma de programação** que organiza o código em torno de **objetos** que representam entidades do mundo real. Em vez de funções soltas, você agrupa **dados** e **comportamentos** dentro de um mesmo objeto.

### 2.2 Os 4 Pilares

| Pilar | Analogia | Semana |
|---|---|---|
| **📦 Abstração** | Ficha de cadastro — guarda só o essencial | Semanas 3–4 |
| **🏗️ Encapsulamento** | Painel do carro — você acelera pelo pedal, sem mexer no motor | Semana 5 |
| **🧬 Herança** | Biologia — filho herda características do pai | Semana 6 |
| **🎭 Polimorfismo** | O verbo "falar" — cada animal fala diferente | Semana 7 |

### 2.3 Classe vs Objeto

```
Classe  →  Forma de bolo (molde)     →  class Aluno { }
Objeto  →  O bolo pronto             →  new Aluno()
Atributo → Ingredientes              →  String nome
Método  →  O que o bolo faz         →  void apresentar()
```

## 4. Atributos e Métodos

### 4.1 Tipos de atributos

```java
// Arquivo: TiposAtributos.java

class Produto {

    // ── ATRIBUTOS DE INSTÂNCIA ──────────────────
    // Cada objeto tem sua própria cópia
    String nome;
    double preco;

    IO.println("Taxa de imposto: " + Produto.TAXA_IMPOSTO);
```

### 4.2 Tipos de métodos

```java
// Arquivo: TiposMetodos.java

class Calculadora {

    // ── MÉTODO VOID ─────────────────────────────
    // Executa ação, mas não retorna valor
    void exibirSoma(int a, int b) {
        IO.println("Soma: " + (a + b));
    }

    // ── MÉTODO COM RETORNO ──────────────────────
    // Declara o tipo antes do nome
    int somar(int a, int b) {
        return a + b;   // "return" devolve o valor
    }

    double calcularMedia(double[] notas) {
        double soma = 0;
        for (double nota : notas) soma += nota;
        return soma / notas.length;
    }

    String classificar(double media) {
        if (media >= 7.0)      return "Aprovado ✅";
        else if (media >= 5.0) return "Recuperação ⚠️";
        else                   return "Reprovado ❌";
    }

    // ── MÉTODO ESTÁTICO ──────────────────────────
    // Chamado pela classe, não pelo objeto
    static double calcularImposto(double valor, double taxa) {
        return valor * taxa;
    }
}

void main() {
    var calc = new Calculadora();

    calc.exibirSoma(10, 5);

    int resultado = calc.somar(10, 5);
    IO.println("Resultado: " + resultado);

    double[] notas = { 8.0, 7.5, 9.0, 6.5 };
    double media = calc.calcularMedia(notas);
    IO.println("Média: " + media);
    IO.println("Situação: " + calc.classificar(media));

    // Método estático — sem criar objeto
    IO.println("Imposto: R$ " + Calculadora.calcularImposto(100.0, 0.12));
}
```

### 4.3 Sobrecarga de métodos (Overloading)

> **Sobrecarga:** mesmo nome de método, parâmetros diferentes. O Java escolhe automaticamente qual versão chamar.

```java
// Arquivo: Sobrecarga.java

class Impressora {

    void imprimir(String texto) {
        IO.println("[TEXTO] " + texto);
    }

    void imprimir(int numero) {
        IO.println("[NÚMERO] " + numero);
    }

    void imprimir(String texto, int vezes) {
        for (int i = 0; i < vezes; i++) {
            IO.println("[" + (i+1) + "] " + texto);
        }
    }

    void imprimir(String titulo, String conteudo) {
        IO.println("=== " + titulo + " ===");
        IO.println(conteudo);
    }
}

void main() {
    var imp = new Impressora();

    imp.imprimir("Olá!");               // 1ª versão
    imp.imprimir(42);                   // 2ª versão
    imp.imprimir("Java 25!", 3);        // 3ª versão
    imp.imprimir("Título", "Corpo");    // 4ª versão
}
```

## 5. Construtores

### 5.1 O que é um construtor?

Construtor é um método especial executado **automaticamente** ao criar um objeto com `new`. Inicializa os atributos na criação.

> **Regras:**
> - Tem o **mesmo nome** da classe
> - **Não tem tipo de retorno** (nem `void`)
> - Pode ter parâmetros ou não
> - Uma classe pode ter **múltiplos construtores** (sobrecarga)

```java
// Arquivo: Construtores.java

class Aluno {
    private String nome;
    private int    idade;
    private String curso;
    private String matricula;

    // ── CONSTRUTOR PADRÃO ────────────────────────
    // Executado quando: new Aluno()
    Aluno() {
        this.curso     = "Não informado";
        this.matricula = "0000";
    }

    // ── CONSTRUTOR COM PARÂMETROS ────────────────
    // Executado quando: new Aluno("Maria", 20, "Informática")
    Aluno(String nome, int idade, String curso) {
        // "this" diferencia atributo do parâmetro de mesmo nome
        this.nome      = nome;
        this.idade     = idade;
        this.curso     = curso;
        this.matricula = gerarMatricula();
    }

    // ── CONSTRUTOR COMPLETO ──────────────────────
    Aluno(String nome, int idade, String curso, String matricula) {
        this(nome, idade, curso);  // chama o construtor acima
        this.matricula = matricula;
    }

    private String gerarMatricula() {
        return "2025" + (int)(Math.random() * 9000 + 1000);
    }

    void apresentar() {
        IO.println("─".repeat(35));
        IO.println("Nome:      " + nome);
        IO.println("Idade:     " + idade);
        IO.println("Curso:     " + curso);
        IO.println("Matrícula: " + matricula);
    }
}

void main() {
    // Usando diferentes construtores
    var a0 = new Aluno();
    var a1 = new Aluno("Maria Silva", 20, "Informática para Internet");
    var a2 = new Aluno("João Santos", 22, "Sistemas", "2025-0042");

    a1.apresentar();
    a2.apresentar();
}
```

## 6. Encapsulamento

### 6.1 O problema sem encapsulamento

```java
// Arquivo: ProblemaSeEncapsulamento.java
// ⚠️ NUNCA faça assim — exemplo didático do que NÃO fazer

class ContaSemProtecao {
    double saldo; // público! qualquer um altera diretamente
}

void main() {
    var conta = new ContaSemProtecao();
    conta.saldo = 1000.00;

    // ⚠️ Nada impede isso:
    conta.saldo = -999999.00;  // saldo absurdamente negativo!
    conta.saldo = 0.001;

    IO.println("Saldo: " + conta.saldo);
}
```

### 6.2 Solução: private + getters e setters

```java
// Arquivo: ContaEncapsulada.java

class ContaBancaria {

    // ── ATRIBUTOS PRIVADOS ──────────────────────
    // private = acessível SOMENTE dentro desta classe
    private String titular;
    private double saldo;
    private String numeroConta;
    private boolean ativa;

    ContaBancaria(String titular, double saldoInicial) {
        this.titular     = titular;
        this.saldo       = Math.max(saldoInicial, 0); // nunca negativo
        this.numeroConta = "AG001-" + (1000 + (int)(Math.random() * 8999));
        this.ativa       = true;
    }

    // ── GETTERS — leitura ───────────────────────
    // Convenção: get + NomeAtributo (boolean usa "is")
    public String  getTitular()     { return titular; }
    public double  getSaldo()       { return saldo; }
    public String  getNumeroConta() { return numeroConta; }
    public boolean isAtiva()        { return ativa; }

    // ── SETTERS — escrita controlada ────────────
    public void setTitular(String titular) {
        if (titular != null && !titular.isBlank()) {
            this.titular = titular;
        } else {
            IO.println("⚠️ Nome inválido.");
        }
    }

    // saldo NÃO tem setter — só muda por depositar/sacar

    // ── MÉTODOS DE NEGÓCIO ──────────────────────
    public void depositar(double valor) {
        if (valor > 0) {
            saldo += valor;
            IO.println("✅ Depósito de R$ " + valor + " realizado.");
        } else {
            IO.println("⚠️ Valor de depósito inválido.");
        }
    }

    public void sacar(double valor) {
        if (!ativa)       { IO.println("⚠️ Conta inativa."); return; }
        if (valor <= 0)   { IO.println("⚠️ Valor inválido."); return; }
        if (valor > saldo){ IO.println("⚠️ Saldo insuficiente: R$ " + saldo); return; }

        saldo -= valor;
        IO.println("✅ Saque de R$ " + valor + " realizado.");
    }

    public void exibirExtrato() {
        IO.println("═".repeat(40));
        IO.println("  CONTA:   " + numeroConta);
        IO.println("  TITULAR: " + titular);
        IO.println("  SALDO:   R$ " + String.format("%.2f", saldo));
        IO.println("  STATUS:  " + (ativa ? "Ativa ✅" : "Inativa ❌"));
        IO.println("═".repeat(40));
    }
}

void main() {
    var c1 = new ContaBancaria("Maria Silva", 500.00);

    c1.exibirExtrato();

    c1.depositar(300.00);
    c1.sacar(100.00);
    c1.sacar(1000.00);  // bloqueado!

    // c1.saldo = -999; // ❌ ERRO de compilação: saldo é private

    IO.println("Saldo atual: R$ " + c1.getSaldo()); // acesso correto

    c1.exibirExtrato();
}
```

| `private`   | ✅ | ❌ | ❌ | ❌ |
| *(padrão)*  | ✅ | ✅ | ❌ | ❌ |

## 7. Herança

### 7.1 O que é herança?

Herança permite que uma classe **filha (subclasse)** herde atributos e métodos de uma classe **pai (superclasse)**. Evita repetição e cria hierarquias lógicas.

```java
// Arquivo: Heranca.java

// ── SUPERCLASSE ──────────────────────────────
class Pessoa {
    // protected = acessível nas subclasses
    protected String nome;
    protected int    idade;
    protected String cpf;

    Pessoa(String nome, int idade, String cpf) {
        this.nome  = nome;
        this.idade = idade;
        this.cpf   = cpf;
    }

    void apresentar() {
        IO.println("Nome:  " + nome);
        IO.println("Idade: " + idade);
        IO.println("CPF:   " + cpf);
    }

    String getNome() { return nome; }
}

// ── SUBCLASSE ────────────────────────────────
// "extends Pessoa" = herda tudo de Pessoa
class Aluno extends Pessoa {
    private String matricula;
    private String curso;
    private double mediaGeral;

    Aluno(String nome, int idade, String cpf, String matricula, String curso) {
        super(nome, idade, cpf); // ← chama o construtor da superclasse (OBRIGATÓRIO 1º)
        this.matricula  = matricula;
        this.curso      = curso;
        this.mediaGeral = 0.0;
    }

    void definirMedia(double media) { this.mediaGeral = media; }

    @Override  // avisa ao compilador que estamos sobrescrevendo
    void apresentar() {
        super.apresentar(); // reutiliza o apresentar() de Pessoa
        IO.println("Matrícula: " + matricula);
        IO.println("Curso:     " + curso);
        IO.println("Média:     " + mediaGeral);
    }
}

class Professor extends Pessoa {
    private String disciplina;
    private String registro;

    Professor(String nome, int idade, String cpf, String disciplina, String registro) {
        super(nome, idade, cpf);
        this.disciplina = disciplina;
        this.registro   = registro;
    }

    @Override
    void apresentar() {
        super.apresentar();
        IO.println("Disciplina: " + disciplina);
        IO.println("Registro:   " + registro);
    }

    void ministrarAula() {
        IO.println(nome + " está ministrando " + disciplina + ".");
    }
```

```java
interface Imprimivel {
    void imprimir();
    void salvarEmArquivo();
}

interface Notificavel {
    void enviarEmail(String dest);
    void enviarSMS(String telefone);

    default void notificarTodos(String dest, String tel) {

// Implementando MÚLTIPLAS interfaces (diferente de herança!)
class Relatorio implements Imprimivel, Notificavel {

    private String conteudo;

        this.titulo   = titulo;
        this.conteudo = conteudo;

    }

    @Override
    public void salvarEmArquivo() {
        IO.println("💾 '" + titulo + "' salvo em arquivo.");
    }

    @Override
    public void enviarEmail(String dest) {
        IO.println("📧 E-mail para " + dest + ": " + titulo);
    }

    @Override
    public void enviarSMS(String tel) {
```

### 9.3 Classe Abstrata vs Interface

| | Classe Abstrata | Interface |
|---|---|---|
| Instanciar | ❌ | ❌ |
| Herança | `extends` (uma só) | `implements` (várias) |
| Atributos | ✅ Pode ter | ❌ Só constantes |
| Construtor | ✅ Tem | ❌ Não tem |
| Métodos concretos | ✅ Pode ter | ✅ Só `default` |
| **Quando usar** | Compartilhar estrutura e código | Definir contrato/comportamento |

```java
class SaldoInsuficienteException extends Exception {
    private double saldoAtual;
    private double valorSolicitado;

    SaldoInsuficienteException(double saldo, double solicitado) {
        super(String.format(
            "Saldo insuficiente. Atual: R$ %.2f | Solicitado: R$ %.2f", saldo, solicitado
        ));
        this.saldoAtual      = saldo;
        this.valorSolicitado = solicitado;

    double getSolicitado() { return valorSolicitado; }

class Conta {
    private String titular;
    private double saldo;

    Conta(String titular, double saldo) {
        this.titular = titular;
        this.saldo   = saldo;
    }

    // "throws" = avisa que pode lançar essa exceção
    void sacar(double valor) throws SaldoInsuficienteException {
        if (valor <= 0)   throw new IllegalArgumentException("Valor inválido: " + valor);
        if (valor > saldo) throw new SaldoInsuficienteException(saldo, valor);

        saldo -= valor;
        IO.println("✅ Saque de R$ " + valor + " realizado.");
    }

    double getSaldo() { return saldo; }
}

void main() {

        try {

            IO.println("Saldo: R$ " + conta.getSaldo());

        } catch (SaldoInsuficienteException e) {
            IO.println("❌ " + e.getMessage());
        } catch (IllegalArgumentException e) {

}
```
